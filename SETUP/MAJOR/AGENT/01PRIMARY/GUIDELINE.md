## โหมดที่ **ไม่** มีในชุดนี้ (ตัดออกโดยเจตนา)

`plan` และ `build` ที่มากับ OpenCode ถูกปิดจาก config (`agent.plan/build = { mode: subagent, hidden: true }`)
— ไม่ใช่ลบไฟล์ → ย้อนกลับได้ และเป็นงานของ `manifest.json` entry `cfg.builtin-off`

## สัญญา `permission` ที่ใช้ได้จริง (ตรวจจาก v2.0.32)

**action ที่มีจริง:** `read` `edit` `glob` `grep` `list` `shell` `subagent` `webfetch` `websearch` `external_directory` `question` `doom_loop` `browser` (+ `submit_plan` จากปลั๊กอิน Plannotator)

| เรื่อง | กฎ |
|---|---|
| ฟอร์มที่ใช้ | `permission:` แผนที่ (`read: allow`) — canonical |
| alias ที่ใช้ได้ | `bash` → `shell` · `task` → `subagent` (ทำงานจริง แต่ให้เขียนชื่อจริงเสมอ) |
| **คีย์ตาย ห้ามใช้** | `skill`, `lsp` — ไม่มีในสคีมา ใส่แล้วเงียบ ไม่มีผล |
| ค่าที่ใช้ได้ | `allow` · `ask` · `deny` (หรือแผนที่แบบมี `*` pattern) |
| `browser` | OpenCode ใส่ `deny` ให้เองโดย default — ไม่ต้องเขียน |
| ค่าปลอดภัยพื้นฐาน | OpenCode ตั้ง `*: allow` เป็นฐาน แล้วทับด้วยรายการของเรา → **สิ่งที่ไม่ได้เขียน = allow** ต้องเขียน deny ให้ครบ |
| `color` | hex 6 หลักเท่านั้น (`^#[0-9a-fA-F]{6}$`) หรือชื่อ theme (`primary`, `info`, …) |
| `mode` | `primary` · `subagent` · `all` |
| `hidden` | ซ่อนจากรายการได้ (ใช้กับ primary ก็ได้ — พิสูจน์แล้ว) |
| `steps` | จำนวนรอบ agentic สูงสุด (ใส่เฉพาะเมื่อจำเป็นจริง) |

**ห้ามเดาคีย์ใหม่** — ถ้าต้องใช้ action ที่ยังไม่เคยยืนยัน ให้รัน probe (`MANIFEST/probes.json`) กับเครื่องจริงก่อน แล้วบันทึกผลลง `01MANIFEST/README.md`

## วิธีเขียนเนื้อหาให้ "แม่น" (ยืมจากชุดที่ปรับด้วย Claude — ใช้ให้ครบ 10 ข้อ)

1. **นิยามขอบเขตให้เป็นสมการ** เช่น "ไฟล์ที่ได้รับอนุญาต = พาธที่ผู้ใช้เขียนไว้ในข้อความของตัวเอง"
2. **แยกจังหวะเวลา** ก่อนอนุมัติ/หลังอนุมัติ ห้ามเขียนลอย ๆ ว่า "ห้ามแก้"
3. **ปิดช่องอ้อม** ระบุชื่อเครื่องมือ/คำสั่งที่ใช้หลบ (subagent, shell, glob, grep)
4. **ข้อยกเว้นต้องมีชื่อและมีจำนวน** ("ข้อยกเว้นเดียวคือ…")
5. **self-check ก่อนเรียกเครื่องมือ** ("ถามตัวเองข้อเดียว: …")
6. **ถูกปฏิเสธ = คำตอบสุดท้าย** ห้ามหาทางอ้อม
7. **ห้าม improvise** ("โหลด skill ไม่ได้ → บอกแล้วหยุด ห้ามแต่งจากความจำ")
8. **สัญญารายงานตายตัว** (ทำอะไร · ไฟล์ที่แตะ · หลักฐาน)
9. **ข้อความที่เครื่องอ่านได้** ต้องเป๊ะตัวอักษร (marker, หัวแผน, ชื่อ field)
10. **ภาษา**: เนื้อหาหลักเป็นไทย แต่ค่า/คีย์/ชื่อเครื่องมือเป็นอังกฤษ และคงคำที่ระบบตรวจไว้ห้ามแปล

## ระดับความแรง (เหมาเข่ง) เป็นงานของ Console ห้ามเขียนซ้ำในไฟล์โหมด
