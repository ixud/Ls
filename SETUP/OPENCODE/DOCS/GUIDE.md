# GUIDE — ใช้ BAZER CONSOLE แบบไม่ต้องเขียนโค้ด

> **EN summary:** Double-click `03WINDOWS/BAZER CONSOLE.vbs`. The Overview tab has three primary buttons: *Check everything*, *Check for changes* (dry run), and *Install / Update all*. Buttons are colour-coded by risk (green / amber / red) and every file write is backed up. Old files live under `Files & Skills → Old stuff` and are moved to `var/quarantine` (never deleted).

## เปิดยังไง

1. ไปที่ `SETUP\OPENCODE\BAZERCONSOLE\03WINDOWS\`
2. ดับเบิลคลิก **`BAZER CONSOLE.vbs`**
3. เบราว์เซอร์จะเปิดเอง (ถ้าไม่เปิด ให้คัดลอกลิงก์ในหน้าต่างดำมาเปิด)

> หน้าต่างดำต้องเปิดค้างไว้ — มันคือเซิร์ฟเวอร์ของ Console ปิดแล้ว Console ก็หยุด

## ปุ่มหลัก (แท็บ ภาพรวม)

1. **ตรวจทุกอย่าง** — กฎ + ความครบ + ของจริง (เริ่มที่นี่ทุกครั้ง)
2. **ตรวจว่ามีอะไรใหม่** — ดูว่าจะเขียนอะไรบ้าง ยังไม่เขียน
3. **ติดตั้ง / อัพเดตทั้งหมด** — เขียนไฟล์จริง (มี backup ทุกไฟล์)
4. **ตรวจของจริง** — ถาม OpenCode จริงว่ามันอ่านค่าที่เราเขียนหรือยัง
5. **ติดตั้งเครื่องมือที่ขาด** — Node / OpenCode / ปลั๊กอิน Plannotator (ใช้เมื่อยังไม่เคยติดตั้ง; ต้องมีเน็ต)

ปุ่มที่มีความเสี่ยงจะมีป้ายบอก 3 ระดับ:

- **ปลอดภัยมาก** — อ่านอย่างเดียว กดได้เลย
- **ดูเหมือนปลอดภัย แต่ตั้งสติดี ๆ** — เขียนไฟล์ของเรา (มี backup) หรือเปลี่ยนค่าที่มีผลกับงาน
- **ไม่ปลอดภัย** — เขียนทับของเดิม/ถอดของ/ติดตั้งโปรแกรม ระบบจะถามยืนยันก่อนเสมอ

### ปุ่มที่อยู่ในแท็บอื่น

| แท็บ | ปุ่ม |
|---|---|
| ไฟล์ & สกิล | **เปิดโฟลเดอร์** 4 ปลายทาง (ตั้งค่า OpenCode · สกิล · MAJOR · backups) · ติดตั้งรายตัว · ดู diff · รีเซ็ต template |
| ประวัติ | **อ่านประวัติล่าสุด (200)** · **ย้อนรอบนี้** |
| โหมด & สิทธิ์ | บันไดเหมาเข่ง · **ตัวแก้ไข Arena (runner/judge + effort รายตัว)** · ซ่อน/คืน Plan & Build · ถอดปลั๊กอินเก่า |
| **ระบบ** | **ปลั๊กอิน gate (ติดตั้ง/อัปเดต/ลงทะเบียน/ถอด)** · เครื่องมือ · Plannotator · backup รายไฟล์ · ข้อมูลเซิร์ฟเวอร์ |
| ตั้งค่า | Quick Access · การตั้งค่าฉบับเต็ม · PSTACK roles + preset |

> ทุกปุ่มเรียกได้จาก **Ctrl+K** (command palette) ด้วย — ถ้าหาปุ่มบนจอไม่เจอ ให้ใช้ palette

## แท็บ ระบบ (ของดูแลระบบ — ไม่อยู่ในเส้นทางงานประจำวัน)

| การ์ด | ทำอะไร |
|---|---|
| **ปลั๊กอิน gate (bazer-flow)** | เทียบไฟล์จริงกับ `AGENT/04PLUGIN/bazer-flow` → ติดตั้ง/อัปเดต (ไฟล์ซากรุ่นเก่าถูกย้ายเข้า backup) · ลงทะเบียนใน `opencode.jsonc` · ถอด |
| **เครื่องมือ** | ติดตั้ง Node/OpenCode/ปลั๊กอิน Plannotator · ดูปลั๊กอินที่ OpenCode เห็น · อัพเดตแพ็กเกจ |
| **Plannotator** | ตรวจว่าเป็นรุ่น CLI-only หรือมีไฟล์ให้แพตช์ · ตั้ง `planningAgents` ให้ส่งกลับ BUDDHA/BAZER |
| **Backup** | ดูรายรอบ + คืน **ไฟล์เดียว** (ระบบสำรองของปัจจุบันก่อนเขียนทับ) |
| **เซิร์ฟเวอร์** | พอร์ต · PID · uptime · home · โฟลเดอร์ปลั๊กอิน |

## Arena แบบยืดหยุ่น (แท็บ โหมด & สิทธิ์)

- **ผู้แข่ง (runner)** และ **กรรมการ (judge)** เลือกได้กี่ตัวก็ได้ และ **ซ้ำโมเดลเดิมได้** (ปุ่ม `＋` บนชิป) — รันพร้อมกัน ลำดับไม่มีความหมาย
- **effort รายตัว**: เปิด “กำหนด effort รายตัว” → 7 กล่อง (default…max) → กด `+ เลือกโมเดล` เพื่อย้ายที่นั่งเข้า effort นั้น
- เก็บลง `~/.agents/pstack-models.md` เป็น **`model#effort` ต่อที่นั่ง** (แหล่งความจริงเดียว):
  ```
  arena runners: opencode-go/beam-free#low, opencode-go/deepseek-v4.1-flash#low
  arena cross-judge pool: opencode-go/glm-5#high
  ```
  ลำดับ = ที่นั่ง · โมเดลซ้ำได้ · ARENA ส่งค่านี้ลง `model` ของ subagent ตรง ๆ (`…flash#low`)
- ไฟล์รุ่นเก่าที่มี `arena runner efforts:` แยก → Console อ่านได้ (fallback) และจะลบบรรทัดนั้นทิ้งเมื่อบันทึกครั้งถัดไป
- รายชื่อโมเดลเหลือเฉพาะ **OpenCode Harness / OpenCode Go Harness** (ค่ายอื่นถูกซ่อน — Console บอกจำนวนที่ซ่อน)



## บันไดเหมาเข่ง (BUDDHA · BAZER — แยกกัน)

อยู่ที่แท็บ **โหมด & สิทธิ์** — มี **2 การ์ด**: บันได BUDDHA และบันได BAZER (ตั้งคนละขั้นได้)
กดขั้นที่ต้องการ → ยืนยัน → **มีผลทันที** (ไม่ต้องกดอัพเดตอีกที) · เขียนทั้ง `opencode.jsonc` และ frontmatter ของ `agents\buddha.md` / `agents\bazer.md`

| ขั้น | ชื่อ | หมายความว่า |
|---|---|---|
| 1 | สุภาพ | อ่าน/แก้ไฟล์ได้ แต่คำสั่ง shell ต้องขออนุมัติ (= BUDDHA รุ่นเก่า) |
| 2 | ปลดกำ | shell รันได้ทันที ไม่ถาม |
| 3 | ออกนอกบ้าน | ออกนอกโปรเจกต์ได้ + เรียกเว็บได้ |
| 4 | ไม่ถามใคร | ไม่หยุดถาม + วนซ่อมตัวเองได้ |
| 5 | เหมาเข่ง | ทุกอย่างจริง ๆ |

กดผิด? มีปุ่ม **ย้อนระดับก่อนหน้า** ของแต่ละบันได อยู่ในหน้าเดียวกัน
ขั้นที่ไฮไลต์คือค่าที่อ่านได้จาก `opencode.jsonc` จริง (ถ้าแก้เองแล้วไม่ตรงขั้นไหน จะขึ้น "กำหนดเอง")
จำไว้: ระดับใหม่มีผลกับ **session ใหม่** (เปิด OpenCode ใหม่)

## ตั้งค่า

- **Quick Access** — โมเดล/effort ของ 4 โหมด + คีย์ copy + ตัวเฝ้า (lock)
- **ARENA** — อยู่ในหน้า BUDDHA: ตั้ง runners / judge
- **ตั้งค่าอื่น ๆ** — โมเดลเริ่มต้น, จำนวนรอบสูงสุด
- **PSTACK roles** — 15 บรรทัด + **preset**: ใช้โมเดลเดียวทั้งชุด หรือแยกงานเขียน/งานตัดสิน

> ไม่มีแนวคิด "gang model" — ตั้งได้ทีละ role และมี preset ให้ ไม่ต้องจำว่าก๊กไหนคุมอะไร

## ถ้าอยากย้อน

แท็บ **ประวัติ** → ทุกครั้งที่เขียนไฟล์จะถูกบันทึก → กด **ย้อนรอบนี้** เพื่อคืนไฟล์ทั้งหมดในรอบนั้น

## เคลียร์ของเก่าให้เหลือแต่ของใหม่

ลำดับที่แนะนำ (ทำครั้งเดียวตอนย้ายจากชุดเก่า):

1. **ติดตั้ง / อัพเดตทั้งหมด** — เขียนทับของใหม่ทับของเดิมที่ชื่อเดียวกัน (buddha/bazer/snack/advisor/skills)
2. ไปแท็บ **ไฟล์ & สกิล → ของเก่า**
   - ติ๊กกลุ่มที่ต้องการ (ค่าเริ่มต้น: agent เก่า · mirror เก่า · ปลั๊กอินเก่า · โฟลเดอร์ปลั๊กอิน)
   - กด **ย้ายของเก่าไป quarantine** → ไฟล์จะถูกย้ายไป `ACTIVE/var/quarantine/<เวลา>/` พร้อม `quarantine.json`
   - กลุ่ม **skill อื่นที่ไม่ใช่ PSTACK** ไม่ถูกติ๊กให้เอง — ดูรายการก่อน ถ้าเป็น skill ที่คุณเขียนเองให้เก็บไว้
3. ถ้า **AGENTS.md** หรือ **pstack-models.md** ยังมีเนื้อหารุ่นเก่าค้าง → ที่แถวของไฟล์นั้นกด **รีเซ็ต** (เขียนทับด้วยแม่แบบจาก MAJOR, สำรองก่อน)
4. กด **ตรวจของจริง** → `เปิด OpenCode ใหม่`

ของที่ถูกย้ายไม่ถูกลบ — กู้คืนได้โดยคัดลอกจาก `quarantine/<เวลา>/<กลุ่ม>/` กลับไปที่เดิมตาม `quarantine.json`

## ถ้ามีอะไรผิดปกติ

```powershell
# 1) ตรวจเครื่อง (ไม่แตะ config จริง)
node "SETUP\OPENCODE\BAZERCONSOLE\01MAIN\ACTIVE\SERVER\tools\selftest.mjs"

# 2) ดูว่า Console คิดว่าอะไรต้องทำ
#    เปิด Console → ภาพรวม → ตรวจว่ามีอะไรใหม่

# 3) ดูว่า OpenCode อ่านค่าอะไรจริง
opencode debug agents
```

- **ติดตั้งแล้วโหมดไม่ขึ้น** → ปิด-เปิด OpenCode ใหม่ (มันอ่าน config ตอนเปิด)
- **ปุ่มขึ้น "ต้องติดตั้ง" ตลอด** → ตรวจว่าไฟล์ต้นทางใน `AGENT/` มีจริง
- **probe `builtin-hidden` ไม่ผ่าน** → มี config อื่นทับอยู่ (เช่น project config) — ดู `opencode debug config`
