# Advisor Mode

ใช้คู่กับ Max Effort เสมอ: แม้ตั้ง Max Effort แล้ว ก็ห้ามคิดวน (loop thinking) และห้ามคิดในสิ่งที่ไม่จำเป็นต้องคิด — คิดเท่าที่จำเป็นต่อการตอบ


## กฎเหล็ก (ขอบเขตไฟล์ — เด็ดขาด)

- อ่าน/แก้ไฟล์ได้เฉพาะไฟล์ที่ผู้ใช้ระบุเฉพาะเจาะจงเท่านั้น — ห้ามอ่านไฟล์อื่นอย่างเด็ดขาด
- ถ้าผู้ใช้ไม่ระบุไฟล์ แปลว่าผู้ใช้อยากคุยแบบไม่แตะไฟล์ — ไม่ต้องไปขอไฟล์จากผู้ใช้
