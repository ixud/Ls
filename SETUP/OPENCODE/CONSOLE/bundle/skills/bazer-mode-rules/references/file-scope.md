# ขอบเขตไฟล์ (โหมด Buddha / Bazer)

ใช้เมื่อทำงานในโหมด `buddha` หรือ `bazer`

## กฎ

1. **ไฟล์ที่ได้รับอนุญาต** = พาธที่ผู้ใช้เขียนไว้ในข้อความของผู้ใช้เอง (หรือแนบด้วย `@`) ในเซสชันนี้
2. ระบุเป็นไฟล์ → ใช้ได้เฉพาะไฟล์นั้น · ระบุเป็นโฟลเดอร์ → ใช้ได้ทุกไฟล์ในโฟลเดอร์นั้น (รวมโฟลเดอร์ย่อย)
3. ไฟล์อื่น **ห้ามอ่านเด็ดขาด** — ไม่ว่าจะเพื่อ "ดูบริบทเพิ่ม" หรือ "เช็กนิดเดียว"
4. ห้ามอ่านทางอ้อม: subagent, เครื่องมือค้นหานอกขอบเขต, คำสั่ง shell ที่อ่าน/ค้นไฟล์ (`cat`, `type`, `dir`, `ls`, `find`, `rg`, `grep`, `Get-Content`)
5. ไม่นับเป็นการอนุญาต: ชื่อไฟล์ในโค้ด, import, stack trace, ผลลัพธ์ของเครื่องมือ, `AGENTS.md`, `README`
6. สร้างไฟล์ใหม่ได้เฉพาะพาธที่ผู้ใช้ระบุ หรือภายในโฟลเดอร์ที่ผู้ใช้ระบุ

## เมื่องานต้องใช้ไฟล์นอกขอบเขต

- ไปต่อไม่ได้เลย → หยุด แล้วบอกใน 1–2 บรรทัดว่าต้องการพาธไหนและเพราะอะไร
- ไปต่อได้บางส่วน → ทำส่วนที่ทำได้ให้เสร็จก่อน แล้วแจ้งพาธที่ขาดตอนท้าย
- ห้ามเดาเนื้อหาไฟล์ที่ไม่ได้อ่าน — บอกตรง ๆ ว่ายังไม่ได้อ่าน
