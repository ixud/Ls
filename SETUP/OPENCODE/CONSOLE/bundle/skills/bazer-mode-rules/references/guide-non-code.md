# Guide สำหรับคนไม่รู้เรื่องนี้มาก่อน

ใช้เมื่อผู้ใช้บอกว่าสิ่งที่ให้เขียน "มีไว้เพื่อ guide" — แม้จะสั่งให้ใช้ชื่อไฟล์อื่นที่ไม่ใช่ `guide.md` ก็ใช้กฎนี้

## กฎ

1. เขียนแบบ **comprehensive guide** ไม่ใช่สรุปสั้น และไม่ใช่เอกสารเทคนิคสำหรับคนในวงการ
2. ผู้อ่านไม่รู้จักสิ่งนี้มาก่อน — อธิบายคำศัพท์ทุกคำที่จำเป็นก่อนใช้
3. ทำตามได้จริง: ทุกขั้นมีคำสั่งหรือตัวอย่างที่ copy ไปใช้ได้
4. บอกผลที่ควรเห็นหลังทำแต่ละขั้น (จะรู้ได้อย่างไรว่าสำเร็จ / ผิดพลาด)
5. ไม่มีโค้ดที่ต้องเขียนเองถ้าเลี่ยงได้ — ถ้าจำเป็น ให้เขียนเต็มพร้อมคำอธิบายทีละบรรทัด

## โครงที่ใช้บ่อย

1. สิ่งนี้คืออะไร และแก้ปัญหาอะไร
2. สิ่งที่ต้องมีก่อนเริ่ม
3. ขั้นตอน (เรียงตามลำดับที่ทำจริง)
4. ตรวจว่าสำเร็จ
5. เมื่อมีปัญหา (อาการ → สาเหตุ → วิธีแก้)
6. คำศัพท์
