# กฎเว้นบรรทัด (Markdown)

ใช้ทุกครั้งที่เขียนหรือแก้ไฟล์ `.md` ในโปรเจกต์นี้

## กฎ

| ระหว่าง | เว้น |
|---|---|
| block เดียวกันภายใต้หัวข้อเดียวกัน (ย่อหน้า, ตาราง, code block, list, quote) | **1 บรรทัดว่าง** |
| ขึ้นหัวข้อใหม่ H2 / H3 / H4 | **2 บรรทัดว่าง** ก่อนหัวข้อ |
| ขึ้นหัวข้อใหม่ H1 | **3 บรรทัดว่าง** ก่อนหัวข้อ |

## ห้าม

- ห้ามยุบบรรทัดว่างที่เว้นไว้แล้ว "เพื่อให้กระชับ" — ตรงไหนเคยเว้น 2 ก็เว้น 2 ตรงไหนเว้น 3 ก็เว้น 3
- ห้ามใช้ `<br>` หรือ HTML แทนบรรทัดว่าง

## ตรวจเร็ว

```powershell
# นับบรรทัดว่างก่อนหัวข้อ H2 ว่ามี 2 บรรทัด
Select-String -Path ไฟล์.md -Pattern "^\s*$" -Context 0,1
```
