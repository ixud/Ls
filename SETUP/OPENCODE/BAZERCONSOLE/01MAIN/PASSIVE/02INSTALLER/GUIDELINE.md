# GUIDELINE — 02INSTALLER

เป็น **ข้อมูล** ของขั้นตอนติดตั้ง ไม่ใช่ตัวรัน (ตัวรันคือ `ACTIVE/SERVER/actions.mjs` → `install-tools`)

## กฎ

1. ทุกคำสั่งติดตั้งต้องมาจาก `install.json` — **ห้ามเขียนซ้ำในโค้ด** (โรคเก่า: รายการเดียวกัน 3 ที่)
2. คำสั่งที่ยังไม่ยืนยันว่าถูกต้อง → `install: null` + `why` อธิบาย ห้ามเดา (เช่น Plannotator)
3. ลำดับต้องเป็น: Node → OpenCode → (Plannotator) → ติดตั้ง MAJOR
4. ทุกขั้นต้อง **dry-run ได้** (แสดงคำสั่งก่อนรัน) และรายงาน exit code จริง
5. ห้ามติดตั้งแบบเงียบ — ต้องมีการยืนยันจากผู้ใช้ (ปุ่ม risk 3)
