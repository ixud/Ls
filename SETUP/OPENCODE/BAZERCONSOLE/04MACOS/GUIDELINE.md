# GUIDELINE — 04MACOS / 05LINUX

ยังว่างโดยเจตนา — ผู้ใช้กำหนดว่า **พัฒนา Windows ให้เสร็จก่อน** แล้วค่อย clone ไปทำบนเครื่องจริง

## เมื่อถึงเวลา

1. ห้ามคัดลอก `03WINDOWS` มาทั้งดุ้นแล้วเปลี่ยนนามสกุล — ให้เขียนตัวเปิดใหม่ให้ตรงกับ OS นั้น
2. ตัวเปิดต้องทำสิ่งเดียวกับ Windows: หา `MAJOR` จากตำแหน่งตัวเอง → `node 01MAIN/ACTIVE/SERVER/index.mjs`
3. ทุกอย่างใน `01MAIN` ต้องรันได้โดยไม่แก้โค้ด (ถ้าต้องแก้ แปลว่ามี path ของ Windows ฝังอยู่ — แก้ที่ต้นเหตุ)
4. เพิ่ม entry ใน `MANIFEST` (พร้อม `platform`) และบันทึกใน `CHANGELOG`
